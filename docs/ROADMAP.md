# Phase gates

- **M0 bootstrap (candidate):** offline MediaWiki XML import, SQLite revision/object storage, FTS5 lookup, deterministic Merkle root, local verification and fixture tests.
- **M1 provenance hardening:** strict XML bounds, deterministic canonicalization contract, source/export provenance, checksum receipts, tamper and corruption tests, true incremental capture semantics.
- **M2 wiki semantics:** link graph, categories, redirects and KoL entity-ID mapping; separate raw, normalized and rendered representations.
- **M3 local browser/API:** read-only Go HTTP service, optional React/TypeScript/SVG UI, typed contracts and explicit authorization checks.
- **M4 research/agents:** project-scoped credentials, policy enforcement, historical retrieval, citations, bounded discovery, auditable workflows.
- **M5 optional ecosystem:** Rust independent verifier, Kotlin client, WASM viewer, ChromaDB and embedding providers only if benchmarks/use cases justify them.

No phase is considered complete from scaffolding or successful compilation alone. Independent re-audit and explicit milestone acceptance are required.
